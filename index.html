À propos

J'aime l'informatique quand elle permet de répondre à un besoin concret. Dans mes projets, je pars d'une consigne ou d'un problème, puis j'essaie de construire une solution claire, organisée et compréhensible.

Mon objectif est de progresser dans les bases importantes : écrire un code lisible, comprendre les erreurs, travailler avec une équipe et expliquer ce que j'ai fait avec des mots simples.

Ma méthode de travail

  • Lire la consigne et repérer le besoin principal.
  • Découper le travail en petites étapes.
  • Tester régulièrement pour éviter les erreurs trop tardives.
  • Garder un code propre, avec des noms compréhensibles.

S2.02 • Python / Algorithmique

Exploration algorithmique avec courbes de Bézier

Création d'une planche de tuiles carrées pour une tilemap. Chaque tuile contient des chemins tracés avec des courbes de Bézier quadratiques.

  • Utilisation de points de contrôle pour construire les courbes.
  • Génération de plusieurs modèles de tuiles à partir d'un même principe.
  • Utilisation de Python, NumPy et Matplotlib.
  • Présentation orale du raisonnement et du programme.
PythonNumPyMatplotlibBézier

Installation et configuration d'un serveur LAMP sur une machine virtuelle Ubuntu MATE. Le but était de faire fonctionner Linux, Apache, MySQL et PHP ensemble.

  • Installation d'Ubuntu MATE dans VirtualBox.

  • Création d'un site de test et d'une base de données.
